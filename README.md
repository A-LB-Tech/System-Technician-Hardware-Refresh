# System Technician – Hardware Deployment & IT Support

## Project Overview

This portfolio documents my hands-on experience supporting hardware refreshes, endpoint deployments, workstation installations, peripheral configuration, and IT asset management across multiple client sites.

My work involved preparing and deploying desktop and laptop systems, performing Windows imaging and provisioning, supporting user data migrations, installing and configuring workstation peripherals, and maintaining accurate hardware records.

It also highlights on-site troubleshooting, end-user support, hardware verification, and coordination with internal IT teams to support successful deployments across different client environments.
