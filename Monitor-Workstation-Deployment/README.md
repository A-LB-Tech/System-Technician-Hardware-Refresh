# 🖥️ Monitor Workstation Deployment

## Task

Assisted with an on-site workstation deployment involving the installation and configuration of monitors and docking monitors across multiple workstations. Set up docking monitor solutions for employees transitioning to laptop-based workstations, replacing traditional docking stations where applicable.

## Work Performed

- Installed and configured standard monitors and docking monitors across multiple workstations
- Set up docking monitors for employees transitioning to laptop-based workstations
- Replaced existing docking stations with docking monitor solutions where applicable
- Connected laptops, displays, and workstation peripherals
- Organized cables and verified display connectivity and functionality

## Skills Demonstrated

- Hardware Deployment
- Workstation Setup
- Monitor Installation
- Hardware Verification
- Cable Management
- Desktop Support
- On-Site IT Support

## Outcome

Multiple workstations were successfully configured with their required monitor setups, with displays verified to be functioning properly after deployment.
