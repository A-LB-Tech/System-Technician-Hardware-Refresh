# 💻 Endpoint Deployment, Imaging & Data Migration

## Project Overview

Performed on-site endpoint deployment and replacement activities across a client environment, preparing and deploying laptops and desktop computers while supporting employee transitions to replacement devices.

Responsibilities included Windows imaging, device provisioning, user data backup and migration using USMT, asset tracking, hardware installation, and coordination with internal IT for software requirements and licensing.

## Work Performed

### Device Imaging & Provisioning
- Imaged new laptops and desktop computers using bootable USB installation media.
- Used ISO-based installation media to prepare replacement systems.
- Provisioned devices for deployment and employee use.
- Prepared replacement hardware for workstation installation.

### Data Backup & Migration
- Backed up employee data from existing devices before replacement.
- Used Microsoft's User State Migration Tool (USMT) to capture and restore user data.
- Assisted with transferring user data to replacement systems.
- Verified migrated data following restoration.

### Asset Management & Device Retirement
- Recorded previous asset tags and associated device information.
- Documented device replacement dates and associated client information.
- Labelled newly deployed replacement devices.
- Identified retired equipment for recycling or repurposing.
- Applied designated green and blue identification labels.
- Kept retired devices separated for their intended disposition.

### Workstation Deployment
- Replaced existing laptops and desktop computers.
- Installed and replaced monitors when required.
- Connected workstation peripherals and cabling.
- Verified hardware functionality following deployment.

### Software Requirements & Internal IT Coordination
- Communicated with employees to identify specialized software requirements.
- Documented requested applications for each workstation.
- Forwarded software requirements to the internal IT team.
- Coordinated application licensing and installation requirements through the appropriate IT personnel.

Successfully prepared and deployed replacement laptops and desktop computers while supporting employee transitions and maintaining device accountability.

User data was backed up and migrated using USMT, retired equipment was identified for recycling or repurposing, and specialized software requirements were documented for internal IT coordination.
